# Display names are auth's

Decided 2026-11-09, at noesis's prompt (noesis
`planning/decision/2026-11-09-a-channel-s-voices-are-its-members.md`). A person's display
name is stored at auth.rvanegas.co, so noesis and Roxana name a person the
way The Floor does (dianoia-auth's task `display-names-are-stored-here.md`).
When someone sets their display name here, The Floor sets it at auth too,
and a name changed at auth reaches The Floor.

noesis already gets a channel's members with their display names, the
`name` of each member in `/noesis/libraries/:handle`. It now uses that name
for each member's own voice: a document of the channel is Claude's account
of what each member thinks, naming each, and the channel's arguments record
which members accept each proposition and which reject it.
