# Chapters for an episode

Erta, 2026-11-16: like a YouTube video's chapters, a published recording
could show the topics it moves through, each a moment to jump to. YouTube's
are written by hand; the suggestion is to draft them from the transcript.
**Rodrigo: for an episode, not for the *Record***, where it is overkill.
Podcasting 2.0 has `<podcast:chapters>` (a JSON file of start times and
titles), which belongs on the item beside what
`each-episode-has-a-page-a-card-and-clips.md` adds, and the episode page would
draw them. Who may set them, and whether drafted chapters are the server
making a public claim about a conversation, is that task's open question about
descriptions, and is answered the same way.
